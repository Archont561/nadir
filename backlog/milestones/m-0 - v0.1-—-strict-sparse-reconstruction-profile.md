## Description

Turn the scaffold into the accepted ADR-012 V0 contract: one bounded calibrated
ImageSet is snapshotted immutably, processed by a qualified CPU-only COLMAP
path, cached through verified stage manifests whose invocation keys are distinct
from output-tree digests, and exported as one canonical local-coordinate
`SparseScene v1`. The exit demo is `nadir process ./images` writing that sparse
scene and cache evidence, with no georeferencing, dense reconstruction, GPU
execution, worker service or mapping products.
